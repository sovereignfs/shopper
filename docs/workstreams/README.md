# Workstreams

A **workstream** is an ordered run of epic tasks that together deliver one goal, with the decisions behind it settled, so that it can be picked up and
run leg by leg without the conversation that produced it. Used as `sovereign` uses them: task detail stays in `docs/epics/`, status in
`ROADMAP.md`, design in `DESIGN.md` and the RFCs. One leg is one branch, one draft PR and one review gate.
